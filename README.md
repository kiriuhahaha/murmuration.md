# Murmuration Moldova — сайт

Главная страница: `index.html`. Сайт статический, сборка не нужна.

- `logos/` — логотипы партнёров
- `media/` — видео и обложка
- `icon-*.png`, `apple-touch-icon.png`, `site.webmanifest` — иконки для вкладки браузера и для телефона
- `og.jpg` — превью ссылки в мессенджерах
- `.nojekyll` — нужен для GitHub Pages
- `CNAME.example` — когда подключишь домен, переименуй в `CNAME`

Проверено на экранах от 320 px (старые iPhone) до 4K, в Chrome, Safari и Firefox, на RU и RO.
